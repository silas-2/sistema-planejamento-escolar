# Sistema de Planejamento Escolar

Sistema web para gestão escolar com notas, médias e dashboard.

## Acesso online

https://silas-2.github.io/sistema-planejamento-escolar/

## Como abrir localmente

Abra o arquivo `index.html` no navegador ou use uma extensão como Live Server no VS Code.

## Deploy

O GitHub Pages publica automaticamente quando há push na branch `main`.

## Arquivos principais

- `index.html`
- `Sistema_de_Planejamento_de_Aulas.css`
- `Sistema_de_Planejamento_de_Aulas.js`
